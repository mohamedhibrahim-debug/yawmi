# يومي · Yawmi

An Arabic-first, offline-first day planner for household work, built as an **iPhone app** (Capacitor) from one web codebase. Data stays on the device.

## What's in the MVP

- **Today.** Week strip, tasks with effort minutes, category, time of day, priority, waiting time and notes. Start/stop timer (one at a time), mark done, move to tomorrow or any day, delete with undo, category filters, starter templates.
- **Waiting time.** "Washing machine" style waits run a countdown that doesn't count as effort. When a wait ends, the app shows an alert while it's open, plus a device notification if you allow it.
- **Arrange my day.** Suggested order and times by period and priority, with a 10-minute gap, period start floors (afternoon 12:00, evening 17:00), no suggestions in the past for today, and a warning when the plan goes over your available effort.
- **Routines.** Repeat on chosen weekdays. Future days show routine tasks ahead of time without creating them. A day's routine tasks are created once, even after you move or delete them.
- **My log.** Done count, tracked minutes per day in your planner time zone, and a manual "adjust time" that never deletes sessions.
- **Settings and backup.** Name, available effort, start time, planner time zone. Export a backup file and restore from it. Restore also accepts the old prototype's export file.
- **Installable PWA.** Works offline after the first visit, with an "update ready" prompt.

## Voice input

- Tap the microphone in the middle of the tab bar, or «قولي اللي وراكي» on Today, and say everything at once. Example: «عايزة أشغل الغسالة وأطبخ الغدا بعد الضهر، وبكرة الصبح أنضف الحمام نص ساعة مهم».
- `src/domain/voice.ts` splits the sentence into tasks. It reads durations («نص ساعة», «ساعة إلا ربع», «خمسة وأربعين دقيقة»), waiting time («وبعدين يستنى ساعة»), the day («بكرة», «يوم الخميس»), the period and priority. Values guessed from keywords, such as غسالة meaning 50 minutes of waiting, are marked «اقتراح».
- She reviews one card per task, taps a chip to change it, then adds them all at once. Typing into the same box works too.
- In the iOS app, speech goes through Apple's speech recognition. In a browser it uses the browser's recognizer, or typing if there is none.

## iOS app

- `ios/` is the Xcode project generated by Capacitor: app id `com.yawmi.app`, display name يومي, Arabic, portrait, with Arabic permission texts for the microphone and speech recognition.
- Native plugins: speech recognition, local notifications (an alarm when a wait ends, even with the app closed), haptics, status bar and app lifecycle.
- Building needs macOS with Xcode. On a Mac, run these from the project folder:

```bash
npm ci
```

```bash
npm run ios:sync
```

```bash
npm run ios:open
```

- Without a Mac, `.github/workflows/ios.yml` runs the tests and an unsigned simulator build on GitHub's macOS runners. Installing on iPhones through TestFlight needs an Apple Developer account and signing secrets.

## Fixed from the prototype

- Closing the welcome dialog with × now saves your defaults, so it doesn't reappear on every visit.
- Routine tasks are visible ahead of time on future days.
- Days, recurrence and daily totals use one planner time zone, including Egypt's daylight-saving switch at midnight.
- Data moved from one localStorage key to IndexedDB, with atomic saves and a check that stops two open tabs from overwriting each other.

## Run it

```bash
npm install
npm run dev
```

```bash
npm test
```

```bash
npm run build
npm run preview
```

`npm run build` type-checks and outputs a static site in `dist/` that any static host can serve over HTTPS.

## Structure

| Path | What it holds |
|---|---|
| `src/domain/` | Pure rules: model, time zones, task and routine operations, day plan, import/export validation |
| `src/storage/` | IndexedDB persistence, revision check, cross-tab updates |
| `src/ui/` | Preact screens, dialogs, formatting |
| `tests/` | Vitest tests for the domain rules and storage |
| `scripts/make-icons.mjs` | Generates the PNG app icons |
